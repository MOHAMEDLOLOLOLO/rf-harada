# rf-harada : maîtriser le monde de la RF

Dépôt de livrables de ma grille Harada « Maîtriser le monde de la RF » : 8 piliers, 8 actions chacun. Chaque case produit un script, une figure et un résultat chiffré.

## Structure

| Dossier | Case | Contenu |
|---|---|---|
| `p1-a1-fourier/` | P1-A1, Fourier | transformée d'un sinus, résultats, fuite spectrale |
| `p1-a1-convolution/` | P1-A1, convolution | convolution, systèmes LTI, lien avec Fourier |
| `p1-a2-modulation/` | P1-A2 | spectre d'un signal AM, lecture d'un spectre |
| `brouillons/` | | essais de travail |

Chaque dossier contient une `FICHE.md` (comment ça marche, à quoi ça sert, pièges) et un `README.md` (contenu, résultats).
